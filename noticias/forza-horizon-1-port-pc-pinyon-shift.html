Forza Horizon 1 ganha port não oficial para PC com Windows

11/10/2026 · CavaloGameNews

🏎️ Os fãs de corrida ganharam uma nova maneira de jogar Forza Horizon 1 no PC. O projeto não oficial Pinyon Shift disponibilizou uma versão de preview jogável que permite executar no Windows o jogo originalmente lançado como exclusivo do Xbox 360 em 2012.

O projeto utiliza uma recompilação do jogo para gerar código nativo para computadores, possibilitando um port para PC e abrindo caminho para aproveitar o clássico de corrida fora do console original.

─────────────

Tempo de instalação e espaço necessário

Segundo as informações divulgadas pelo projeto, o processo de instalação pode levar entre 20 e 60 minutos. Também é necessário ter aproximadamente 25 GB de espaço livre em disco.

─────────────

Como baixar Forza Horizon 1 para PC

O projeto Pinyon Shift está disponível no GitHub. Para conferir os arquivos e as instruções de instalação, acesse a página oficial da versão 0.4.0c.

🔗 Download: https://github.com/arcanite24/pinyon-shift/releases/tag/v0.4.0c

⚠️ Vale lembrar que este é um projeto não oficial e ainda está em fase de preview jogável. A compatibilidade e o funcionamento podem variar conforme o computador e a configuração utilizada.
